# Cozy Cat — releases

바탕화면에 사는 작은 3D 고양이, **Cozy Cat** 의 Windows 설치 파일을 배포하는 곳입니다.
A tiny 3D cat that lives on your Windows desktop. This repository only hosts the installers.

- 소개 · 구매 / About & purchase: https://cozy-cat-companion.vercel.app/
- 최신 설치 파일 / Latest installer: https://github.com/dorisurararara-crypto/cozy-cat-releases/releases/latest/download/CozyCat-Setup.exe

설치한 앱은 새 버전이 나오면 스스로 받아서 적용합니다. 이곳을 다시 찾아올 필요는 없습니다.
Installed apps update themselves; there is no need to come back here.

Windows 10 / 11 (x64). 앱을 쓰려면 구매 영수증의 라이선스 키가 필요합니다.
A licence key from your purchase receipt activates the app.
