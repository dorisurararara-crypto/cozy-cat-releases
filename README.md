# Cozy Cat — releases

바탕화면에 사는 작은 3D 고양이, **Cozy Cat** 의 설치 파일을 배포하는 곳입니다. **무료로 입양하세요.**
A tiny 3D cat that lives on your desktop. **Free to adopt.** This repository only hosts the installers.

- 소개 / About: https://mycozycat.com/
- Windows 설치 파일 / Windows installer: https://mycozycat.com/download
- Mac 설치 파일 (Apple Silicon) / Mac installer: https://mycozycat.com/download/mac

설치한 앱은 새 버전이 나오면 스스로 받아서 적용합니다. 이곳을 다시 찾아올 필요는 없습니다.
Installed apps update themselves; there is no need to come back here.

Windows 10 / 11 (x64) · macOS (Apple Silicon). 키도 로그인도 필요 없습니다. 꾸미기용 G 충전만 선택으로 판매합니다.
